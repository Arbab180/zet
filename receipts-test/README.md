# Test receipts

Drop receipt photos here to try the scanner against them:

```
npm run scan:check receipts-test/whatever.jpg
```

This folder is inside the project, so Claude can open the same image and
check the model's answer against the receipt independently — which is the
point of putting them here rather than on the Desktop.

Real receipts show suppliers and amounts, so this folder is gitignored.
Nothing in it is committed.
